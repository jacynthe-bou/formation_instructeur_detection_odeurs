# Formation instructeur — Détection d’odeurs

Prototype initial de la plateforme de formation en ligne.

## Première version

- Tableau de progression
- Module 1 interactif
- Étapes théorie, vidéo, observation et pratique
- Simulation de remise vidéo
- Déblocage du module suivant

Ce dépôt servira de base pour la plateforme finale et pourra ensuite être enrichi avec authentification, base de données, vidéos et validations d’instructeur.
